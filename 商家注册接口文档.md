# 商家注册接口文档

## 接口路径

```
POST /it/shop/register
```

> 网关白名单：`/us/shop/register`（未登录可访问）

## 请求参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| shopName | String | 是 | 店铺名称 |
| phone | String | 是 | 手机号 |
| code | String | 是 | 短信验证码 |
| password | String | 是 | 登录密码 |
| nickname | String | 是 | 昵称 |
| logo | String | 否 | 店铺 logo URL |
| description | String | 否 | 店铺描述 |

```json
{
  "shopName": "我的小店",
  "phone": "13800138000",
  "code": "123456",
  "password": "123456qq",
  "nickname": "张三",
  "logo": "https://xxx.com/logo.png",
  "description": "优质商品，品质保证"
}
```

## 返回值

```json
{
  "code": 200,
  "message": "操作成功",
  "data": null,
  "success": true
}
```

## 调用链路

```
POST /it/shop/register
  │
  ▼ 网关 StripPrefix=1 → /shop/register
  │
ym-item ShopController.register()
  │
  ▼ ShopServiceImpl.addShop(dto, ip)
  │   │
  │   ├─ 1. BeanUtils.copyProperties → RegisterShopDTO
  │   │
  │   ├─ 2. userFeign.registerShop(registerDTO) ──→ Feign ──→ ym-user
  │   │                                                    POST /user/shop/register
  │   │                                                      │
  │   │                                                UserController.registerShop()
  │   │                                                      │
  │   │                                                UserServiceImpl.registerShop()
  │   │                                                  ① 验手机号是否已注册
  │   │                                                  ② 验短信验证码
  │   │                                                  ③ 建 User（role=1 商家）
  │   │                                                  ④ 建 UserProfile
  │   │                                                  ⑤ return userId
  │   │
  │   └─ 3. saveShopAndRating(userId, dto)
  │          ① 存 Shop（shopName, logo, description）
  │          ② 存 ShopRating（评分初始记录）
  │
  └─ return Result.success()
```

## 涉及服务

| 服务 | 作用 |
|------|------|
| ym-item | 接收前端请求，编排注册流程，存 Shop + ShopRating |
| ym-user | 创建商家用户（User + UserProfile） |

## 涉及文件

| 文件 | 说明 |
|------|------|
| `ym-item/.../ShopController.java` | `POST /shop/register` 入口 |
| `ym-item/.../ShopServiceImpl.java` | `addShop()` 编排逻辑 |
| `ym-api/.../client/UserFeign.java` | Feign 调用 `ym-user` |
| `ym-user/.../UserController.java` | `POST /user/shop/register` 用户注册 |
| `ym-user/.../UserServiceImpl.java` | `registerShop()` 创建用户+Profile |
| `ym-api/.../dto/RegisterShopDTO.java` | 注册参数 DTO |
| `ym-item/.../dto/ShopDTO.java` | 前端请求体 DTO |
