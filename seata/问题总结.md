## 当前报错

访问 `http://192.168.150.101:7091` 登录 `seata/seata` 时报错：

```
WeakKeyException: The signing key's size is 152 bits which is not secure enough for the HS256 algorithm.
HS256 要求密钥 >= 256 bits，当前密钥224 bits（也有可能是152 bits输出，取决于实际文件内容）
```

## 已尝试的操作

- 多次修改 `secretKey` 值，但 `sed` 替换可能没生效，或 `docker restart` 不会重新挂载文件
- 用 `docker compose down && up` 重新创建容器后，问题依旧
- JWT 库版本：jjwt-api-0.10.5.jar（Seata 2.0.0 内置）

## 核心问题

`secretKey` 长度不够。HS256 要求 >= 32 个 ASCII 字符（256 bits）。

**直接改 VM 文件**：
```bash
cd /root/seata
# 先确认当前值
grep secretKey application.yml
# 改成 32+ 字符
sed -i 's/secretKey:.*/secretKey: 12345678901234567890123456789012/' application.yml
# 确认改成功了
grep secretKey application.yml
# 必须 down + up
docker compose down
docker compose up -d
```

`12345678901234567890123456789012` = 32字符 = 256 bits，刚好满足最低要求。
