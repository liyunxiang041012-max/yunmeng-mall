## ❌ 遗留问题：Seata DB 无数据 & 控制台看不到

### 现象
1. 分布式事务跑通了（日志完整验证）
2. 但 Navicat 查 `seata.global_table` 无记录
3. 控制台 `http://192.168.150.101:7091` 能登录但事务列表为空
4. API `/api/v1/console/globalSession/all` 返回 404

### 根因：`seataio/seata-server:2.0.0` 镜像非常坑
- entrypoint 脚本**覆盖挂载的 `application.yml`**，导致 `store.db.url` 等配置丢失
- 事务可能走了内存模式而非 DB 持久化
- 官方正确的镜像是 `apache/seata-server:2.0.0`，但 Docker Hub 拉不下来（GFW）

### 解决方案（按优先级）
1. **换镜像**：找办法拉 `apache/seata-server:2.0.0`（代理/镜像加速/手动下载）
2. **环境变量注入**：不用 volumes 挂载，全部通过 docker-compose `environment` 传参
3. **镜像代理**：使用 `docker.m.daocloud.io` 等国内镜像加速器
4. **直接下载 tar 包**：手动 load 进 Docker
